# Data, model and component usage

## Public insurer PDFs

Public accessibility does not grant redistribution rights. No redistribution
license was established for the three insurer documents. Their original PDFs,
full extracted text, real-document reports and screenshots remain in ignored
`local_data/`. The repository contains URLs, hashes, access metadata, aggregate
results and page annotations. Do not add insurer PDFs to Git or the container.
Users upload their own authorized public/anonymized copies for analysis.

## Original synthetic fixtures

`evaluation/fixture_texts.json` and `evaluation/blind_fixtures.json` are original
AI-assisted text authored for this project, with no insurer clauses copied.
`evaluation/generate_fixtures.py` draws text using ReportLab. It uses the installed
Arial font on this Windows machine, or DejaVu Sans on Linux; no system font binary
is copied to this repository. PDFs contain subsets needed to render their text.
Embedding flags are inspected in `evaluation/font_embedding.json`.

[Microsoft font FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq)
permits document embedding subject to the font's embedding flags; embedded font
data is not a general permission to redistribute extracted font binaries. Check
the recorded flags before distributing fixtures. Fixture generation on a new
machine can change PDF byte hashes due to font differences; the manifest records
the actual generated bytes. Synthetic labels are engineering expectations, not
legal advice or expert-annotated insurance data.

## Official legal sources

Full fetched LexUZ pages are retained only in ignored local research storage.
The catalogue redistributes short attributed excerpts and exact provision
references, with independent engineering interpretations. Original Uzbek wording
was inspected; amended Russian text is labelled an unofficial translation by LexUZ.
